Crea desde cero una aplicación completa llamada MaternIA en Replit.

TECNOLOGÍA: React Native + TypeScript + Expo + React Navigation + AsyncStorage.

OBJETIVO: App de acompañamiento emocional para mujeres embarazadas y en posparto. Debe funcionar en Expo Go (escaneando QR en iPhone). Debe tener arquitectura preparada para HealthKit de Apple (que se activará después con Development Build).
